## Bill of Materials

The [Bill of Materials (BOM)](daisy-chain-bom.csv) contains components for 1 board. If users of this repo discover that any components are unavailable, please maintain an `alternate-components.md` file in this folder that lists approved alternates.

[^1]: This number does not include screws or standoffs. With screws and standoffs included, the unique part count is 16 and total parts is 37. Users are advised to not have their assembly vendor place screws and standoffs.
